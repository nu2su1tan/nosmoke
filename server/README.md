# NoSmoke server

Бэкенд для ленты сообщества, близких и ИИ-коуча.

## Запуск

```bash
cd server
dart pub get
ANTHROPIC_API_KEY=sk-ant-... PORT=8080 DATA_FILE=data.json dart run bin/server.dart
```

- Без `ANTHROPIC_API_KEY` сервер работает, но коуч отвечает 503, и приложение
  переключается на офлайн-подсказки.
- `DATA_FILE` — файл, куда сохраняется состояние (JSON). Без него данные
  живут только в памяти. Для большой нагрузки замените `Db` на настоящую БД.
- Ключ Anthropic хранится только на сервере, в приложение он не попадает.

## Подключение приложения

В приложении: Настройки → Сообщество и ИИ → Сервер. Или при сборке:
`flutter build ... --dart-define=SERVER_URL=https://ваш-сервер`.

Сервер нужно ставить за HTTPS (nginx, Caddy, Cloud Run и т. п.).

## Что хранится

Анонимный псевдоним и токен, посты и комментарии, связи «близкий», три
числа прогресса (дни без сигарет, дни в программе, не выкурено) и
сообщения поддержки. Деньги, срывы и дневник на сервер не отправляются.
Пользователь может стереть всё из приложения (Настройки → Отключить и
удалить мои данные).
